Catalog — Alex Store

Publish changes

Edits are saved to this browser only. Visitors still see the published catalog.sql. To publish, download both files below and replace their copies in the repo, then push — Pages rebuilds in about a minute.
catalog.sql is what this site reads. catalog.json is the same data as plain JSON: the Android app fetches it, because it cannot run SQLite in a browser the way this page does.

Add a collection

Collections are editorial, not for sale. They are independent of the product catalog — no price, no stock, and nothing links between them.

Search index

Precomputes a ternlight vector for every product so visitors never run the model on the catalog - only on their own query. The @ternlight/base engine (~7 MB gzipped, one self-contained WebAssembly module) is fetched to this browser only.
